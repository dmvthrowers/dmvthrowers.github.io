How to Yo-Yo

String · Wind · Throw · Sleep · First 100 Tricks · Trick History

LEARN & REFERENCE How to Yo-Yo Gear & Maintenance Yo-Yo Science Yo-Yo History Filipino Yo-Yo History Collecting Yo-Yos For Teachers Resources FAQ

New to yo-yo? Start here. This page walks you through stringing, winding, throwing, and your first tricks, gives you a 100-trick path with a free video or guide for each one, shows where to keep learning after that, and tells the story of how tricks evolved. There are a lot of great teachers out there, so we point you to them. Every trick name links to a tutorial.

Learning is faster in person. Come to a meetup. Loaners are provided, all ages, all levels, always free.

Glossary

Quick definitions for words you’ll hear at meetups and read on forums. Each links to where we explain it in full, on this page or our Gear, Science, and Collecting guides.

Yo-yo glossary
TermMeaningMore
0A–5A, X, APThe styles of play, from modern responsive through freehand, plus the X division and Artistic Performance.[46]Read more
B-gradeA yo-yo sold at a discount for finish flaws or vibe.Read more
BandaloristA yo-yo collector.Read more
Bearing size (A, C, MR85…)Letter or part-number sizes for yo-yo bearings; C is today’s standard.Read more
BimetalA yo-yo made of two metals, usually aluminum with steel rims for more rim weight.Read more
BindWinding string into the gap to make an unresponsive yo-yo return.[26]Read more
BSTBuy/sell/trade: forum marketplaces for used yo-yos.Read more
ClickerA hand tally counter judges use to score elements.[80]Read more
CounterweightThe weight on the free end of the string in 5A.Read more
ElementOne specific, scorable movement inside a trick.[80]Read more
Fixed axleA yo-yo whose string wraps a solid axle instead of a bearing; a “fixie.”Read more
FloatyA yo-yo that feels light and drifts through tricks.Read more
Green Triangle (GT)A mount that is basically a knot with the yo-yo in the loop, invented by Paul Escolar; the pop-out side matters.[82]Read more
H, V, W, O shapesProfile shapes: rim-heavy H, straight V, stepped W, and rounded O (organic).Read more
HubstackCapped bearings on the hubs you can grab while the yo-yo spins.Read more
KonKaveFrank Difeo’s curved, string-centering bearing from 2003.Read more
MountA position the string can be in with the yo-yo on it; in 3A, mounts are called houses.[81]Read more
RejectionPushing the string into the yo-yo’s wall so the spin kicks it out of the gap.[106]Read more
Responsive / unresponsiveComes back with a tug, or needs a bind.[25]Read more
Silicone / flowableThe response material in most unresponsive yo-yos, as pads or poured into a groove.Read more
RestartSpinning a stopped yo-yo back up on the string instead of rewinding it.[95]Read more
SleeperThe yo-yo spinning at the end of the string.[18]Read more
Stop, discard, detachContest deductions of −1, −3, and −5.[80]Read more
String tensionTwist in the string; too much makes loops and kinks.[22]Read more
String type 6, 8, 9String thickness by strand count; type 8 is standard.Read more
SuicideReleasing a string loop and catching it again on your finger; invented by Paul Escolar from a diabolo trick of the same name.[44]Read more
Throw downThe basic throw every trick starts from.[83]Read more
TransaxleA sleeve or bearing around the axle so the string doesn’t rub a fixed axle.Read more
Trick ladderA set list of tricks in rising difficulty used at contests.[23]Read more
VibeVibration you feel through the string, usually from misaligned halves.Read more
